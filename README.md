# Yasin Core

Central runtime and infrastructure layer for the Yasin AI Ecosystem.

## Overview

Yasin Core is the kernel of the Yasin platform.

It provides:

- Runtime management
- Configuration system
- Event communication
- Plugin architecture
- AI Provider abstraction
- Shared infrastructure


## Ecosystem

Yasin Core connects:

- Yasin-Agent
- YasinRelay
- YasinCoder
- YasinPress
- YasinHub
